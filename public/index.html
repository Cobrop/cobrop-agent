Service online

This is the backend API for the CoBrop Agent. It runs the queue worker, capabilities, and approval endpoints. There's no UI here — open the monitoring dashboard separately.

  • GET /health — service status
  • GET /approvals?status=pending — review queue
  • GET /agent/activity — live activity
  • POST /agent/run — trigger a capability
  • POST /webhooks/* — Supabase event receivers
